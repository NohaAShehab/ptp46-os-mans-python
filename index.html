🐍 Python Clean Code Cheatsheet

Write readable, maintainable & pythonic code

PEP 8 · Zen of Python · Best practices

📛 Naming & Style

✔️ Variables & Functions
Use snake_case for variables, functions, methods.
Constants: UPPER_SNAKE_CASE. Classes: PascalCase.
❌ DON'T
def GetUserData(): pass
userAge = 42
MAX_SIZE = 100 # misleading if mutable
✅ DO
def get_user_data(): pass
user_age = 42
MAX_SIZE = 100 # constant
🎯 Meaningful Names
Avoid single letters (except loop counters i, j). Use descriptive names: delay_seconds not d.

⚙️ Functions Matter

📏 Single Responsibility
Each function does one thing, does it well, and does it only.
❌ Too many tasks
def process_user(data):
# validate + transform + save + email
pass
✅ Decompose
def validate_user(data): ...
def save_user(user): ...
def send_welcome_email(email): ...
🔄 Pure Functions (prefer)
Avoid side effects; same input → same output. Easier to test/debug.
# bad: modifies global
# good: returns new value

💬 Comments & Docs

📌 Write self-documenting code
Use comments only for "why", not "what". Use docstrings for public APIs.
✅ Docstring example
def calculate_tax(amount: float, rate: float) -> float:
"""Compute tax based on amount and percentage rate."""
return amount * rate / 100
❌ Obvious comment
i += 1 # increment i by 1
🧹 TODO & FIXME
Mark temporary notes but keep them tracked.

⚠️ Error Handling

🎯 Specific Exceptions
Catch concrete exceptions, never except: bare.
❌ Silent & broad
try:
value = int(data)
except:
pass
✅ Explicit & informative
try:
value = int(data)
except ValueError as e:
logger.error(f"Invalid int: {e}")
raise
📦 Use context managers for resources
Files, locks, connections → with statement.

🔍 Type Hints (3.5+)

📈 Improve readability & tooling
Use mypy, pydantic, or just annotations.
from typing import List, Optional

def process_items(items: List[str], limit: Optional[int] = None) -> dict:
...
✅ Clear intent
def greet(name: str) -> str:
return f"Hello, {name}"
✨ Use `Union`, `Optional`, or `|` in Python 3.10+
str | None instead of Optional[str]

🧩 Pythonic Data Handling

📋 List/Dict comprehensions
More expressive than map/filter for simple cases.
❌ Verbose loop
squares = []
for i in range(10):
squares.append(i*i)
✅ Clean comprehension
squares = [i*i for i in range(10)]
evens = {i for i in data if i % 2 == 0}
🗂️ Avoid overcomplicating (max 2 loops/conditions)
If complex, use plain loops for readability.

🔐 Context Managers

📂 File handling
Always use with open(...) as f → automatic closing.
with open("data.txt", "r") as file:
content = file.read()
# file closed outside block
🧵 Locks / database sessions
with threading.Lock(): or sqlalchemy session.
🔧 Custom context manager (contextlib)
from contextlib import contextmanager

📝 F-strings & Modern Python

✨ F-strings over .format() / %
Clearer and faster (Python 3.6+).
❌ Old style
print("Hello %s, you have %d" % (name, count))
✅ Modern f-string
print(f"Hello {name}, you have {count} messages")
📅 pathlib over os.path
Object-oriented paths → cleaner and cross-platform.
from pathlib import Path
cfg = Path.home() / ".config" / "app" / "settings.toml"

🏗️ Classes & OOP Clean

🧱 Favor composition over inheritance
Keep hierarchies shallow. Use @dataclass for data containers.
✅ dataclass
from dataclasses import dataclass

@dataclass
class Point:
x: float
y: float
🕵️‍♂️ Repr & Str
Define __repr__ for debugging, __str__ for users.

🧹 Tooling & Automation

⚡ Use formatters & linters
ruff / black / isort / flake8 → enforce style.
# Install and run
pip install ruff black
ruff check . && black .
🧪 Pre-commit hooks
Automate formatting before each commit.
📏 Line length: 79 (or 88 for black)
Keep code readable without horizontal scrolling.

🚫 Dangerous Patterns

⚠️ Mutable default arguments
Never use list/dict as default value — it persists across calls.
❌ Bug hidden
def add_item(item, lst=[]):
lst.append(item)
return lst
✅ Use None pattern
def add_item(item, lst=None):
if lst is None:
lst = []
lst.append(item)
return lst

🌀 Lazy & Efficient

⚙️ Use generators for large data
Yield instead of returning list → memory efficient.
def read_large_file(file_path):
with open(file_path) as f:
for line in f:
yield line.strip()
🔁 Enumerate over range(len)
Use enumerate for index/value pairs.
for idx, value in enumerate(items):
print(f"{idx}: {value}")
