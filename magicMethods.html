🐍 Python Magic Methods Complete Cheatsheet

Dunder Methods — Unlocking Python's Inner Magic ✨

🔧 Initialization & Representation

__new__(cls, *args, **kwargs) Creates new instance before __init__
Controls instance creation. Useful for singletons or immutable objects. Called automatically before __init__.
__init__(self, *args, **kwargs) Constructor - initializes instance
Sets up initial state. Most commonly overridden magic method. Called after __new__.
__del__(self) Destructor (not guaranteed to be called)
Called when object is garbage collected. Use with caution - finalizers can cause issues.
__repr__(self) Official string representation
Used by repr(), should be unambiguous and ideally eval-able. For developers.
__str__(self) User-friendly string representation
Used by str(), print(), and f-strings. For end users. Falls back to __repr__ if missing.
__format__(self, format_spec) Custom formatting for f-strings
Controls f"{obj:format_spec}" and format(obj, format_spec).
__hash__(self) Returns integer hash for dict/set keys
Must be consistent with __eq__. If __eq__ defined, __hash__ becomes None unless manually set.
__bool__(self) Truthiness value
Called for bool(obj) and if obj:. Falls back to __len__ if not defined.
📘 Example:
class Book:
    def __new__(cls, title):
        print(f"Creating instance of {title}")
        return super().__new__(cls)
    
    def __init__(self, title, author):
        self.title = title
        self.author = author
    
    def __repr__(self):
        return f"Book('{self.title}', '{self.author}')"
    
    def __str__(self):
        return f"{self.title} by {self.author}"
    
    def __bool__(self):
        return len(self.title) > 0
    
    def __hash__(self):
        return hash((self.title, self.author))

# Usage
book = Book("1984", "Orwell")
print(repr(book))  # Book('1984', 'Orwell')
print(str(book))   # 1984 by Orwell
print(bool(book))  # True
💡 Pro tip: Always define __repr__ for debugging. If __eq__ is defined, consider defining __hash__ for dictionary keys.

🔍 Attribute Access Control

__getattr__(self, name) Called when attribute lookup fails normally
Only called for missing attributes. Perfect for dynamic attributes or fallbacks.
__setattr__(self, name, value) Intercepts all attribute assignment
Use super().__setattr__() to avoid recursion. Great for validation or logging.
__delattr__(self, name) Called when deleting attribute
Intercepts del obj.attr. Use with super().__delattr__().
__getattribute__(self, name) Called for EVERY attribute access
Extremely powerful but dangerous. Can break normal attribute access if not careful.
__dir__(self) Customizes dir() output
Returns list of attributes. Affects auto-completion in IDEs.
📘 Example: Lazy Loading & Validation
class LazyPerson:
    def __init__(self, name):
        self.name = name
        self._data = {}
    
    def __getattr__(self, name):
        # Called only for missing attributes
        print(f"Computing {name} dynamically...")
        return f"Dynamic {name}"
    
    def __setattr__(self, name, value):
        # Validate age before setting
        if name == 'age' and value < 0:
            raise ValueError("Age cannot be negative!")
        super().__setattr__(name, value)
    
    def __getattribute__(self, name):
        # Called for ALL attribute access
        print(f"Accessing {name}")
        return super().__getattribute__(name)

p = LazyPerson("Alice")
p.age = 30          # Validated
# p.age = -5        # Raises ValueError
print(p.non_existent)  # Computed dynamically
⚠️ Warning: __getattribute__ is called for every attribute access including self.attr inside the method itself - always use super() to avoid infinite recursion.

📦 Container & Sequence Protocol

__len__(self) Length of container
Called by len(obj). Essential for sequence-like objects.
__getitem__(self, key) Element access by index/key
Enables obj[index], obj[key], and slicing.
__setitem__(self, key, value) Assign element by index/key
Enables obj[index] = value and obj[key] = value.
__delitem__(self, key) Delete element by index/key
Enables del obj[index] and del obj[key].
__contains__(self, item) Membership test
Enables 'item in obj'. Falls back to iteration if not defined.
__iter__(self) Returns iterator
Enables for loops, list(), tuple(), etc. Should return iterator object.
__reversed__(self) Returns reverse iterator
Called by reversed(). Not required for reversed() to work if __len__ and __getitem__ exist.
__missing__(self, key) Dict subclass: handle missing keys
Called when key missing in dict subclasses (not regular dict).
📘 Example: Custom Range Class
class CustomRange:
    def __init__(self, start, end):
        self.start = start
        self.end = end
        self._data = list(range(start, end))
    
    def __len__(self):
        return len(self._data)
    
    def __getitem__(self, index):
        if isinstance(index, slice):
            # Handle slicing
            return self._data[index]
        if index < 0 or index >= len(self):
            raise IndexError("Index out of range")
        return self._data[index]
    
    def __setitem__(self, index, value):
        self._data[index] = value
    
    def __contains__(self, item):
        return item in self._data
    
    def __iter__(self):
        return iter(self._data)
    
    def __reversed__(self):
        return reversed(self._data)

# Usage
cr = CustomRange(1, 5)
print(len(cr))        # 4
print(cr[2])          # 3
print(3 in cr)        # True
for num in cr:
    print(num)        # 1,2,3,4
print(list(reversed(cr)))  # [4,3,2,1]
💡 Pro tip: Implement __getitem__ and __len__ to get automatic iteration, membership tests, and reversed() support!

➕ Arithmetic Operators

__add__(self, other)+ addition
__sub__(self, other)- subtraction
__mul__(self, other)* multiplication
__truediv__(self, other)/ true division
__floordiv__(self, other)// floor division
__mod__(self, other)% modulo/remainder
__pow__(self, other[, modulo])** power (optional modulo)
__matmul__(self, other)@ matrix multiplication (Python 3.5+)
__neg__(self)-obj unary negation
__pos__(self)+obj unary positive
__abs__(self)abs(obj) absolute value
__invert__(self)~ bitwise NOT
📘 Example: 2D Vector Class
class Vector2D:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    def __repr__(self):
        return f"Vector2D({self.x}, {self.y})"
    
    def __add__(self, other):
        return Vector2D(self.x + other.x, self.y + other.y)
    
    def __sub__(self, other):
        return Vector2D(self.x - other.x, self.y - other.y)
    
    def __mul__(self, scalar):
        # Scalar multiplication
        if isinstance(scalar, (int, float)):
            return Vector2D(self.x * scalar, self.y * scalar)
        return NotImplemented
    
    def __rmul__(self, scalar):
        # For scalar * vector
        return self.__mul__(scalar)
    
    def __abs__(self):
        return (self.x ** 2 + self.y ** 2) ** 0.5
    
    def __neg__(self):
        return Vector2D(-self.x, -self.y)

# Usage
v1 = Vector2D(2, 3)
v2 = Vector2D(1, 4)
print(v1 + v2)    # Vector2D(3, 7)
print(v1 - v2)    # Vector2D(1, -1)
print(v1 * 3)     # Vector2D(6, 9)
print(3 * v1)     # Vector2D(6, 9)
print(abs(v1))    # 3.605551275463989
print(-v1)        # Vector2D(-2, -3)
📌 Note: Return NotImplemented (not raise NotImplementedError) to let Python try reverse operation.

🔄 Reflected & In-place Operators

__radd__(self, other)Reflected addition: other + self when self.__add__ fails
__rsub__(self, other)Reflected subtraction: other - self
__rmul__(self, other)Reflected multiplication: other * self
__rtruediv__(self, other)Reflected division: other / self
__iadd__(self, other)In-place addition: += (should return self)
__isub__(self, other)In-place subtraction: -=
__imul__(self, other)In-place multiplication: *=
__itruediv__(self, other)In-place division: /=
__imatmul__(self, other)In-place matrix multiplication: @=
📘 Example: Accumulator with In-place Operations
class Accumulator:
    def __init__(self, value=0):
        self.value = value
    
    def __repr__(self):
        return f"Accumulator({self.value})"
    
    def __add__(self, other):
        # Regular addition
        return Accumulator(self.value + other)
    
    def __radd__(self, other):
        # For other + accumulator
        return Accumulator(other + self.value)
    
    def __iadd__(self, other):
        # In-place addition (modifies self)
        self.value += other
        return self  # Must return self
    
    def __isub__(self, other):
        self.value -= other
        return self

# Usage
acc = Accumulator(10)
print(5 + acc)      # Accumulator(15) - uses __radd__
acc += 5            # Uses __iadd__
print(acc)          # Accumulator(15)
acc -= 3
print(acc)          # Accumulator(12)
💡 Pro tip: In-place methods should modify self AND return self to support chaining: obj += 5 += 3

⚖️ Comparison Operators

__eq__(self, other)== equality
__ne__(self, other)!= inequality (defaults to not __eq__ if missing)
__lt__(self, other)< less than
__le__(self, other)<= less than or equal
__gt__(self, other)> greater than
__ge__(self, other)>= greater than or equal
📘 Example: Comparable Person
from functools import total_ordering

@total_ordering  # Implements missing comparisons automatically
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def __repr__(self):
        return f"Person('{self.name}', {self.age})"
    
    def __eq__(self, other):
        if not isinstance(other, Person):
            return NotImplemented
        return self.age == other.age
    
    def __lt__(self, other):
        if not isinstance(other, Person):
            return NotImplemented
        return self.age < other.age
    
    def __hash__(self):
        return hash((self.name, self.age))

# Usage
alice = Person("Alice", 30)
bob = Person("Bob", 25)
charlie = Person("Charlie", 30)

print(alice == bob)   # False
print(alice == charlie)  # True
print(bob < alice)    # True
print(alice > bob)    # True (from @total_ordering)
print(alice >= charlie)  # True (from @total_ordering)

# Works with sorting
people = [alice, bob, charlie]
print(sorted(people))  # Sorted by age: Bob(25), Alice(30), Charlie(30)
💡 Pro tip: Use @total_ordering decorator to define just __eq__ and one comparison method (e.g., __lt__) and get all others for free!

🎯 Callable & Context Manager

__call__(self, *args, **kwargs) Make instance callable like a function
Enables obj(). Great for closures, decorators, or stateful functions.
__enter__(self) Enter runtime context
Called when entering 'with' block. Should return resource object.
__exit__(self, exc_type, exc_val, exc_tb) Exit runtime context
Called when exiting 'with' block. Can handle exceptions. Return True to suppress exception.
📘 Example 1: Callable Counter
class Counter:
    def __init__(self):
        self.count = 0
    
    def __call__(self, *args, **kwargs):
        self.count += 1
        print(f"Called {self.count} times")
        return self.count

# Usage as callable
counter = Counter()
counter()  # Called 1 times
counter()  # Called 2 times
print(counter.count)  # 2
📘 Example 2: Context Manager for File Operations
class ManagedFile:
    def __init__(self, filename, mode='r'):
        self.filename = filename
        self.mode = mode
        self.file = None
    
    def __enter__(self):
        self.file = open(self.filename, self.mode)
        return self.file  # Resource to use in 'with' block
    
    def __exit__(self, exc_type, exc_val, exc_tb):
        if self.file:
            self.file.close()
        
        if exc_type:
            print(f"Exception occurred: {exc_val}")
            # Return False to propagate exception, True to suppress
            return False

# Usage
with ManagedFile('test.txt', 'w') as f:
    f.write('Hello, World!')
# File automatically closed even if exception occurs

# Context manager with exception handling
try:
    with ManagedFile('test.txt', 'r') as f:
        content = f.read()
        print(content)
except FileNotFoundError:
    print("File not found")
📌 Note: __exit__ receives None for all args if no exception. Return True to suppress exceptions (use carefully!).

🔐 Descriptor Protocol (Property Control)

__get__(self, instance, owner) Get attribute value. Called when accessing descriptor attribute.
__set__(self, instance, value) Set attribute value. Called when assigning to descriptor attribute.
__delete__(self, instance) Delete attribute. Called when deleting descriptor attribute.
__set_name__(self, owner, name) Called when descriptor is assigned to class attribute (Python 3.6+).
📘 Example: Type-checked Attribute Descriptor
class TypedProperty:
    def __init__(self, expected_type):
        self.expected_type = expected_type
        self.name = None
    
    def __set_name__(self, owner, name):
        # Automatically capture attribute name
        self.name = name
    
    def __get__(self, instance, owner):
        if instance is None:
            return self
        return instance.__dict__.get(self.name)
    
    def __set__(self, instance, value):
        if not isinstance(value, self.expected_type):
            raise TypeError(f"{self.name} must be {self.expected_type.__name__}")
        instance.__dict__[self.name] = value
    
    def __delete__(self, instance):
        del instance.__dict__[self.name]

class Person:
    name = TypedProperty(str)
    age = TypedProperty(int)
    
    def __init__(self, name, age):
        self.name = name  # Uses descriptor
        self.age = age    # Uses descriptor

# Usage
p = Person("Alice", 30)
print(p.name, p.age)  # Alice 30
# p.name = 123        # Raises TypeError: name must be str
# p.age = "thirty"    # Raises TypeError: age must be int
💡 Pro tip: Descriptors power @property, @staticmethod, and @classmethod. Use them for reusable attribute logic!

💾 Serialization, Copy & Pickling

__reduce__(self) Controls pickling: returns (callable, args, state) tuple.
__reduce_ex__(self, protocol) Pickle with specific protocol version.
__getstate__(self) What to pickle (return custom state).
__setstate__(self, state) Restore state when unpickling.
__copy__(self) Shallow copy support for copy.copy().
__deepcopy__(self, memo) Deep copy support for copy.deepcopy().
📘 Example: Custom Pickling with Secret Data
import pickle
import copy

class SecureData:
    def __init__(self, public_data, secret_data):
        self.public = public_data
        self._secret = secret_data  # Don't want to pickle this
    
    def __repr__(self):
        return f"SecureData('{self.public}', '***')"
    
    def __getstate__(self):
        # What gets pickled
        state = self.__dict__.copy()
        del state['_secret']  # Remove sensitive data
        return state
    
    def __setstate__(self, state):
        # Restore object from pickled state
        self.__dict__.update(state)
        self._secret = None  # Reset secret after unpickling
    
    def __copy__(self):
        # Shallow copy
        return SecureData(self.public, None)
    
    def __deepcopy__(self, memo):
        # Deep copy
        return SecureData(copy.deepcopy(self.public, memo), None)

# Usage
data = SecureData("hello", "super_secret_123")
pickled = pickle.dumps(data)
restored = pickle.loads(pickled)
print(restored.public)  # hello
print(restored._secret)  # None (secret not restored)
⚠️ Security note: Never unpickle data from untrusted sources! Pickle can execute arbitrary code.

__subclasses__(self) Return list of immediate subclasses.
__class_getitem__(cls, key) Support for generic types: List[int] (Python 3.7+).
__index__(self) Convert to integer for indexing/slicing (e.g., bin(), hex()).
__int__(self) Convert to int: int(obj).
__float__(self) Convert to float: float(obj).
__complex__(self) Convert to complex: complex(obj).
__round__(self, n) Round: round(obj, n).
__trunc__(self) Truncate: math.trunc(obj).
__floor__(self) Floor: math.floor(obj).
__ceil__(self) Ceiling: math.ceil(obj).
📘 Example: Advanced Indexing & Type Hints
class CustomIndex:
    def __init__(self, value):
        self.value = value
    
    def __index__(self):
        # Allows use as index in slicing
        return self.value
    
    def __int__(self):
        return self.value
    
    def __round__(self, ndigits=0):
        return CustomIndex(round(self.value, ndigits))

class GenericContainer:
    def __class_getitem__(cls, key):
        # Support for Generic[T] syntax
        print(f"Creating generic container with type: {key}")
        return f"Container[{key.__name__}]"

# Usage with indexing
idx = CustomIndex(3)
items = [10, 20, 30, 40, 50]
print(items[idx])  # 40 (index 3)

# Generic type hint support
print(GenericContainer[int])  # Creating generic container with type: <class 'int'>

# Custom numeric conversions
num = CustomIndex(42)
print(bin(num))   # 0b101010 (uses __index__)
print(int(num))   # 42
💡 Pro tip: __index__ is crucial for custom numeric types that need to be used as slice indices or in binary/hex conversions.

⚡ Asynchronous Methods (Async/Await)

__await__(self) Return iterator for awaitable object. Enables await obj.
__aiter__(self) Return async iterator for async for loops.
__anext__(self) Return awaitable for next item in async iterator.
__aenter__(self) Enter async context manager (async with).
__aexit__(self, exc_type, exc_val, exc_tb) Exit async context manager.
📘 Example: Async Context Manager & Iterator
import asyncio

class AsyncResource:
    async def __aenter__(self):
        print("Acquiring async resource...")
        await asyncio.sleep(0.1)
        return self
    
    async def __aexit__(self, exc_type, exc_val, exc_tb):
        print("Releasing async resource...")
        await asyncio.sleep(0.1)
    
    async def do_work(self):
        print("Doing async work")
        await asyncio.sleep(0.1)

class AsyncCounter:
    def __init__(self, limit):
        self.limit = limit
        self.current = 0
    
    def __aiter__(self):
        return self
    
    async def __anext__(self):
        if self.current >= self.limit:
            raise StopAsyncIteration
        self.current += 1
        await asyncio.sleep(0.1)
        return self.current

# Usage
async def main():
    # Async context manager
    async with AsyncResource() as resource:
        await resource.do_work()
    
    # Async iterator
    async for num in AsyncCounter(5):
        print(f"Count: {num}")

# asyncio.run(main())  # Uncomment to run
📌 Note: Async methods require Python 3.5+ and are used with asyncio and async/await syntax.

🎓 Magic Methods Summary: These special methods (also called "dunder" methods) enable your classes to integrate seamlessly with Python's built-in behavior.

💡 Best Practices: Only implement magic methods when needed. Always call super() when overriding to maintain parent class behavior.

🔗 Remember: Magic methods are looked up on the class, not instance. Avoid dynamic addition of magic methods after class definition.
